# Purefolk platform

The new customer website and Nucleus Admin are being developed under apps/web using Next.js, TypeScript and Supabase.

The existing root-level GitHub Pages website is intentionally left untouched until the replacement has been reviewed and is ready to launch.

See docs/architecture/purefolk-platform.md for the system boundaries, catalogue model, order safety rules and SEO requirements.

The SQL proposal in supabase/migrations is not yet applied to the connected production database.
