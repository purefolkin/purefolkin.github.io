# Neclues — Purefolk Control

Development foundation for the Neclues admin interface.

- This folder is a development-only surface on `build/neclues-foundation`.
- It does not replace or modify the existing live admin or website.
- No production Supabase writes or deployment are performed from this scaffold.
- The UI must be connected to the approved Purefolk architecture and existing data model before live use.

## First implementation boundary

Establish the navigation and module boundaries for product catalog, sellable variants, recipes and ingredients, suppliers, costs and pricing, orders, kitchen operations, delivery, customer feedback, analytics, and system settings.

## Safety rule

Do not publish this page to production or add live data mutations until authentication, authorization, data contracts, lifecycle rules, and publication safeguards have been verified.
